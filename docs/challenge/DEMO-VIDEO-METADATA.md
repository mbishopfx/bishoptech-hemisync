# Demo video metadata

## Suggested title

Cognistration — WebMCP agentic listening session demo

## Suggested description

Cognistration turns an intention into a bounded listening session that a person
and a browser agent can shape together. This live demo shows the public
challenge cockpit, intent clarification, tone comparison, an arrive/practice/
close ritual plan, bounded tone calibration, a technical-only session recipe,
the human-confirmed machine preview, safety-aware routing, and the optional
agent-to-agent payment challenge.

The public flow is available at https://cognistration.com/try. The live app does
not diagnose, treat, or guarantee a neurological outcome. Audio playback,
account access, payment, and private workspace actions remain user-controlled.
