# Tutorial Discoverability Rebuild

## Objective

Rebuild Cognistration's public tutorial experience into a clear, motion-rich learning hub that teaches safe and effective platform use, explains the underlying science responsibly, and earns discoverability across meditation, self-exploration, astral projection, metaphysics, deep dreaming, and remote viewing topics without keyword stacking.

## Original Request

Remake `/tutorial` with anime.js and advanced motion; explain how to use the platform and the science behind it; target the named search themes with semantic phrases and granular breadcrumb-linked pages where useful; improve schema, metadata, URL structure, robots and AI-search visibility; and use the supplied logo everywhere except the existing header, including shared-link metadata.

- Authority: `requested`

- Existing plan facts: Use anime.js and advanced motion; prioritize instructional clarity; cover science at a high level; target the named topical clusters and semantic phrases; add granular breadcrumb pages if evidence supports them; link remote-viewing material to CIA studies; optimize metadata, structured data, URLs, robots, and AI-search legibility; use the supplied logo everywhere except the header and for social previews.
