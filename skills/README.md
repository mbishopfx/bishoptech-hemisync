# Cognistration operating skills

These five public skills are reusable routing guidance for agents integrating with Cognistration. They describe the public MCP, WebMCP, REST, discovery, UI, and consent boundaries; they do not grant authorization.

- [Agentic routing](./cognistration-agentic-routing/SKILL.md)
- [Tone orchestration](./cognistration-tone-orchestration/SKILL.md)
- [Account safety](./cognistration-account-safety/SKILL.md)
- [Agent evaluation](./cognistration-agent-evaluation/SKILL.md)
- [Feedback](./cognistration-feedback/SKILL.md)

The machine-readable index is [`/.well-known/agent-skills/index.json`](https://cognistration.com/.well-known/agent-skills/index.json). For the published remote contract, use [`/api/mcp`](https://cognistration.com/api/mcp) and [`/docs`](https://cognistration.com/docs).
